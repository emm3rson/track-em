# Track'Em v4.0.0

Track'Em v4.0.0 is the current Android release baseline. It is an offline-first personal finance tracker backed by local SQLite storage.

## Included

- Dashboard summaries for funds, net position, spending, savings, payables, and recent activity.
- Expense, income, transfer, payable, receivable, and lent-money workflows with editing and history.
- Wallet, card, savings, and investment account management with reconciliation and bundled institution branding.
- Local backup and restore, demo mode, appearance controls, and startup recovery.

## Release boundaries

- Android only, with no cloud sync, multi-user mode, or legacy-data migration.
- Financial data remains on the device in local SQLite databases.
- Institution logos are bundled locally; runtime branding downloads are not required.
